# Strings and Conditional Statements

## Strings: 'Sequence of Characters'

- Strings variables can be enclosed in various different ways:

```
str1 = 'jdlfjsldjfs'
str2 = "lsjfljs"
str3 = """sljdfljsljfls"""
```

## Escape Seq Char:

- \n : for next line
- \t : for tab space

## Operations in Strings:

- Concatenation:(`str1 + str2`)
- Length of str (`len(str)`)
